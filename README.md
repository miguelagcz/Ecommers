# E-commerce Website

Sitio de comercio electrónico desarrollado con HTML, CSS y JavaScript. El proyecto reúne una página de inicio promocional, catálogo de productos y vistas de tienda y producto, con una interfaz orientada a la exploración de artículos y la navegación entre secciones.

## Funcionalidades y secciones

- Página principal con hero y contenido promocional.
- Catálogo con productos destacados y colecciones.
- Vistas independientes para tienda y detalle de producto.
- Navegación entre secciones informativas y comerciales.
- Elementos visuales de promoción y llamadas a la acción.
- Estilos adaptables a distintos tamaños de pantalla.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Ejecutar localmente

El proyecto utiliza archivos estáticos y no requiere instalación de dependencias.

```bash
git clone https://github.com/miguelagcz/Ecommers.git
cd Ecommers
```

Abre `index.html` en tu navegador. Puedes usar Live Server para facilitar el desarrollo.

## Enfoque técnico

Este proyecto demuestra organización de páginas estáticas, estructura de un catálogo, estilos responsive y construcción de una experiencia visual de tienda online. Las funciones de pagos, inventario o gestión de pedidos no se consideran disponibles a menos que estén implementadas explícitamente en el código.
