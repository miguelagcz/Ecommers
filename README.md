# E-commerce Website

Sitio web de comercio electrónico enfocado en presentar productos de forma clara y atractiva, con navegación entre catálogo, tienda, blog, información de la empresa, contacto y carrito.

## ✨ Características

- Diseño responsive.
- Página principal con hero y promociones.
- Catálogo de productos.
- Productos destacados y nuevas colecciones.
- Navegación a tienda, blog, información y contacto.
- Carrito de compras.
- Secciones promocionales.
- Interfaz adaptada para dispositivos móviles.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Font Awesome

## 🚀 Cómo ejecutarlo

No requiere instalación de dependencias.

1. Clona el repositorio:

```bash
git clone https://github.com/miguelagcz/Ecommers.git
```

2. Abre `index.html` en tu navegador.
